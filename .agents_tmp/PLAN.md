# 1. OBJECTIVE
Создать локальную (на ПК пользователя) систему полного цикла разработки ПО: планирование → анализ → программирование → тестирование → запуск → отладка.
Система управляется локальной ИИ, использует облачные API дляresource intensive задач, отказоустойчива, оптимизирована по токенам.

**Требования:**

# 3. APPROACH OVERVIEW
Использовать **OpenHands SDK** как ядро системы (создание агентов, tool calling, управление задачами). Локальная модель — **Ollama** с Mistral 7B и CodeQwen 7B (llama.cpp бэкенд). Агенты запускаются как subprocess'ы с ограничением по RAM/CPU. Облачные API подключаются через ключи в .env. Мониторинг — локальный лог-файл. Конфигурация — JSON/YAML файлы с hot-reload.

**Почему OpenHands SDK:**
- Готовый фреймворк для создания AI-агентов
- Поддержка tool calling
- Python — легко расширять
- Активная разработка

# 4. IMPLEMENTATION STEPS

## Этап 1: Подготовка окружения + Установочный пакет
1.1. Создать установочный скрипт `setup.bat` для Windows

1.3. Проверка Git: версия, наличие
1.4. Проверка NVIDIA GPU и драйверов
1.5. Проверка RAM
1.6. Проверка свободного места на диске
1.7. Если компонент отсутствует — скачать и установить
1.8. Логирование каждого шага в `logs/setup.log`
1.9. Создание рабочей директории проекта
1.10. Создание скрипта автозапуска ( через планировщик Windows )

## Этап 2: Установка и настройка локальной LLM
2.1. Скачать и установить Ollama для Windows
2.2. Скачать модель Mistral 7B: `ollama pull mistral`
2.3. Скачать CodeQwen 7B: `ollama pull codeqwen`
2.4. Настроить Ollama как API-сервер (порт 11434)
2.5. Протестировать инференс

## Этап 3: Установка OpenHands SDK + Веб-интерфейс
3.1. Создать Python-проект: `uv init ai-factory`
3.2. Установить зависимости: `pip install openhands`, `ollama`, `prometheus-client`
3.3. Настроить .env с API-ключами (шаблон с placeholders)
3.4. Проверить базовую работоспособность
3.5. Установить веб-интерфейс (похож на текущий OpenHands UI: чат + код + терминал)
3.6. Настроить автозапуск веб-сервера

## Этап 4: Архитектура агентов
4.1. Создать базового агента-оркестратора (Main Agent)
4.2. Создать специализированных агентов:

   - Coder Agent (программирование)

4.3. Настроить коммуникацию между агентами (очередь задач)

## Этап 5: Подключение облачных API

# 5. TESTING AND VALIDATION
**Успех = когда:**
- Система запускается одним скриптом (`setup.bat` → `run.bat`)
- Веб-интерфейс доступен по адресу (например, http://localhost:8000)
- Задача "создай hello world на Python" выполняется полностью (план → код → тест → запуск)
- Агенты работают параллельно без зависаний
- При убийстве агента система восстанавливает его за 10-30 секунд
- Логи пишутся в файл с timestamp
- Токены учитываются (счетчик в логах)
- Конфиг меняется — агенты перезапускаются
- После перезагрузки ПК система запускается сама
- После перезагрузки система помнит задачи и контекст
- RAM не превышает 14 GB при 3 агентах
- GPU используется для локальной LLM
